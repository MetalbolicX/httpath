### Methodology assignment rationale

- **Basic** — single-file edits, config/docs drift, no behavioral semantics.
  Standard checks (`pnpm run build`, `pnpm test`, `npm pack --dry-run`) suffice.
- **TDD** — changes the request lifecycle, streaming, shutdown, or limiter
  state machine. Behavior must be pinned by tests before the refactor lands.
- **SDD** — introduces or changes cross-cutting contracts (startup guard, LAN
  TLS policy, health endpoints, logging format). Requires a written spec /
  interface update and architectural sign-off before code.
