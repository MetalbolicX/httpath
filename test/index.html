🎯 Usage Examples

# Start server on default port (8080)
node dist/index.mjs

# Start with custom port
node dist/index.mjs --port 3000

# Start with hot-reload enabled
node dist/index.mjs --reload

# Start serving a different directory
node dist/index.mjs --path /path/to/your/files

# Combined options
node dist/index.mjs --port 3000 --path ./public --reload
