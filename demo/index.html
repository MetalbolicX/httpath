💻 Usage Examples

Basic Usage
# Start server on port 8080
httpath

# Custom port and directory
httpath --port 3000 --path ./public
Development Mode
# Enable hot-reload for development
httpath --reload

# Full development setup
httpath --port 3000 --path ./src --reload
