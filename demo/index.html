💻 Usage Examples

Basic Usage
# Start server on port 8080
httpath

# Custom port and directory
httpath -p 3000 -d ./public
Development Mode
# Disable live-reload (enabled by default)
httpath --no-live-reload

# Full development setup
httpath -p 3000 -d ./src
